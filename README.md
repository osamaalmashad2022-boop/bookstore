# متجر دار المعرفة للكتب الورقية ومستشار القراءة الذكي 📚
### Perpetual Zero-Cost Mobile-First Physical Arabic Bookstore & Smart Book Recommender

منصة متكاملة وجاهزة لتسليم العميل (Turnkey Product) لبيع **الكتب الورقية فقط**، مبنية بمعمارية خفيفة وسريعة جداً ومصممة من الأساس لتجربة **الهاتف المحمول (Mobile-First)** مع استبعاد Next.js لتفادي تعقيدات الـ SSR والـ Hydration وثقل الحزم.

تعتمد المنصة على خطط استضافة سحابية **مجانية للأبد بنسبة 100% (Free Forever Tiers)** بدون أي بطاقات ائتمانية أو فترات تجريبية تنتهي لاحقاً.

## 🌟 الميزات الجوهرية (Core Features)

1. **واجهة استخدام خفيفة مصممة للهاتف (Mobile-First UX):**
   - شريط تنقل سفلي سريع (Bottom Navigation Bar) للتنقل بالإبهام.
   - كروت كتب أنيقة ومحسنة للشاشات الصغيرة مع شارات المخزون الفوري (`متوفر` / `متبقي X فقط` / `نفدت الكمية`).
   - شارات الهوية القرائية (Book DNA Badges): مستوى الصعوبة، عدد الصفحات، وقت القراءة المقدر، واستدعاء *"لماذا تقرأ هذا الكتاب؟"*.
   - نافذة تصفح مقتطف من الكتاب (Look Inside Modal) لمعاينة الفهرس والصفحات الأولى.

2. **مستشار الكتب الذكي (Smart Book Advisor) بنظام هجين دائم:**
   - **الوضع الأول (اختبار الـ 3 خطوات):** تحديد المجال، المستوى القرائي (مبتدئ / متوسط / متقدم)، والهدف الفرعي وحجم الكتاب.
   - **الوضع الثاني (بحث باللغة الطبيعية):** كتابة استفسار حر بالعربية مع مقترحات سريعة.
   - **مسار القراءة المتدرج (Progressive Reading Path):** توليد مسار من 2 إلى 3 كتب (مدخل تأسيسي ⬅️ فهم وتطبيق ⬅️ تعمق).
   - زر مباشر **"أضف المسار الكامل للسلة بخصم الباقة (10%)"** لرفع متوسط قيمة الطلب (AOV).
   - محرك محلي سريع يعمل دائماً مباشرة على قاعدة البيانات حتى في حال انعدام مفاتيح الـ LLM أو انقطاعها.

3. **سلة مشتريات جانبية وحساب الشحن والدفع عند الاستلام (COD):**
   - سلة منبثقة متزامنة مع `localStorage` مع شريط تقدم للشحن المجاني (عند تجاوز 600 ج.م).
   - حاسبة شحن فورية لجميع المحافظات المصرية الـ 25 مع حساب إجمالي الدفع نقداً عند الاستلام.
   - إنشاء الطلب وتوليد فاتورة واتساب جاهزة وإرسال العميل مباشرة لمحادثة المتجر عبر `wa.me`.

4. **لوحة تحكم المتجر وميزة الملء التلقائي الذكي (Admin Dashboard):**
   - **1-Click Smart Auto-Fill:** كتابة اسم الكتاب أو الـ ISBN والضغط على "جلب البيانات تلقائياً" لجلب العنوان والمؤلف والغلاف وعدد الصفحات والنبذة من Google Books API مجاناً.
   - إدارة المخزون وتعديل الأسعار وحذف الكتب.
   - متابعة الطلبات وتحديث حالاتها مع زر تواصل مباشر على واتساب العميل بضغطة واحدة.
   - تعديل أسعار الشحن وأيام التوصيل لكل محافظة.
   - تحليلات استفسارات المستشار الذكي (Content Gap Analytics) لمعرفة الكتب الأكثر طلباً.

## 🛠️ المعمارية والتقنيات (Approved Tech Stack)

- **الواجهة الأمامية (Frontend):** Vite + React 19 + TypeScript + Tailwind CSS (RTL عربي أصيل بخط Readex Pro و Amiri).
- **الخادم البرمجي (Backend API):** Node.js + Express REST API.
- **بوابة المتابعة ورمز الـ QR (Follow Hub):** صفحة هبوط خفيفة وتفاعلية للهاتف (`follow.html`) بحركات Pure SVG ميكرو، ثلاثية الأبعاد بـ CSS، وخالية تماماً من الإيموجي أو أي اعتماديات خارجية لسرعة قصوى عند مسح رمز الـ QR من أغلفة الكتب.
- **فواصل وكروت الطباعة المرفقة (Printable QR Bookmarks):** تصميم جاهز للطباعة المباشرة (`qr_card.html`) يتضمن فواصل كتب ورقية وكروت شحنات ترويجية بكود خصم `MAQBARA10`.
- **قاعدة البيانات (Database):** SQLite محلي مدمج فائق السرعة، أو **Turso Serverless SQLite** (مجاني للأبد: 5 جيجابايت تخزين + 500 مليون قراءة شهرياً).
- **التشغيل:** متوافق 100% مع بيئات Node.js الحديثة (v20, v22, v24) على Windows وLinux.

## 🚀 التشغيل المحلي السريع (Quick Local Start)

```bash
# 1. تثبيت الاعتماديات لجميع الأجزاء
npm install
npm --prefix server install
npm --prefix client install

# 2. تهيئة قاعدة البيانات والكتب الأولية (Psychology, Philosophy, Self-Development)
npm run seed

# 3. تشغيل الواجهة والخادم معاً بضغطة واحدة
npm run dev
```

- الواجهة الأمامية: `http://localhost:5173`
- الخادم وقاعدة البيانات: `http://localhost:5000`

## 🌐 دليل النشر المجاني للأبد ($0/Month Free Forever Deployment)

### 1. قاعدة البيانات (Database):
- أنشئ حساباً مجانياً على [Turso](https://turso.tech) (لا يتطلب بطاقة بنكية).
- نفذ `turso db create dar-almaarefa`.
- ضع رابط قاعدة البيانات والـ Auth Token في متغيرات البيئة:
  ```env
  DATABASE_URL=libsql://dar-almaarefa-[org].turso.io
  DATABASE_AUTH_TOKEN=your-turso-token
  ```

### 2. الخادم الخلفي (Backend API):
- انشر مجلد `server/` مجاناً على **Render.com** (Web Service Free) أو **Railway** أو **Fly.io**.
- أضف متغيرات البيئة (`DATABASE_URL`, `DATABASE_AUTH_TOKEN`, `MERCHANT_PHONE`).

### 3. الواجهة الأمامية (Frontend):
- انشر مجلد `client/` على **Vercel** أو **Netlify** أو **Cloudflare Pages** (استضافة مجانية للأبد وسريعة جداً).
- في إعدادات الـ Rewrite في Vercel/Netlify، وجّه طلبات `/api/*` لرابط السيرفر الخلفي.
